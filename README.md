# delivery_tracking  
## 택배 추적 알리미

이 프로젝트는 다양한 택배 서비스의 배송 상태를 추적하고 알림을 제공하는 애플리케이션입니다.

## 기능

- 여러 택배 회사의 배송 상태 자동 추적
- 배송 상태 변경 시 알림 제공
- 택배 정보 목록 관리
- 주기적인 배송 상태 업데이트

## 지원 택배사

- 대한통운
- 경동택배
- 한진택배
- 우체국택배
- 롯데택배
- 로젠택배

## 설치 방법

1. 리포지토리 클론
```bash
git clone https://github.com/dbswnschl/delivery_tracking.git
```

2. 필요한 패키지 설치
```bash
pip install -r requirements.txt
```

## 사용 방법

1. 설정 메뉴에서 사용할 택배사를 선택
2. 추적할 택배 번호 입력
3. 스케줄러 설정 (기본값: 1시간 간격)
4. 알림 설정 구성

## 프로젝트 구조

- `mod_basic.py`: 메인 모듈 및 택배사별 스크래핑 로직
- `model.py`: 데이터베이스 모델
- `setup.py`: 플러그인 설정
- `templates/`: 웹 인터페이스 템플릿
- `static/`: 정적 파일 (CSS, JS 등)
